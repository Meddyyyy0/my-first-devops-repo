# Коротко для защиты

1. Stateful означает, что у приложения есть постоянные данные: сообщения в БД и файлы в отдельном томе.
2. MySQL и PostgreSQL используют разные служебные схемы. Поэтому сначала создаём родную PostgreSQL-схему средствами Mattermost, затем переносим данные через официальный pgloader.
3. До переноса останавливаем запись и делаем резервную копию.
4. После переноса сравниваем ID и тексты всех сообщений, запускаем новую версию и проверяем HTTP.
5. Флаг ставится только после успеха. Следующий запуск пропускает backup и перенос.
6. --remove-orphans удаляет старый MySQL-контейнер, но исходный именованный том остаётся для восстановления.
7. GitHub Secrets передают пароли в окружение; паролей в репозитории нет.
8. Продемонстрируй два успешных Actions, localhost:8065 и исходные сообщения. Временный runner после проверки отключён.
